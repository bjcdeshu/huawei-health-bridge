# 日期范围分析

`health.py analyze` 只读取本地私有 SQLite，不联网、不读取认证，不输出诊断或综合健康分数。

## 时间和覆盖

默认使用 UTC+8 最近七个已结束日期，避免上午查询时把当天缺测混入完整日比较。可以使用 `--days 30`，或用 `--start` 和 `--end` 指定区间。基线默认为分析区间之前的 28 天，不与分析区间重叠。

查询结果应一起阅读：范围、生成时间、最近采集时间、测量时间、有效样本数量、缺失日期和未结束日期。采集成功时间不是测量时间；有数据库记录也不一定有可用于比较的数值。

## 睡眠与日统计

睡眠按北京时间醒来日期归属。「主睡眠」采用当天最长且至少 180 分钟的会话启发式，不等于医学上的夜间睡眠分类。其他会话单独列出；存在重叠或归属歧义时，标记并排除不可靠汇总，不重复累计。

静息心率使用日平均；全天心率保留日极值，不能代替静息心率。HRV 只在同来源内比较，不使用未核实单位套阈值。血氧日最低值没有持续时间，不能据此确定持续低氧或排除健康问题。

## 不完整响应

字段被新响应省略时，上一有效值可以保留，但 `retained` 标记说明它不是本次新观测。分析将保留字段与当前有效字段区分。旧记录没有字段级采集时间时记为来源时间未知，不补造时间。

缺失值和缺失日期不补零。运动概要只代表手表记录的运动，不等于全天活动量。VO2max 保留真实测量日期；不把旧测量用于近期恢复判断。

这些规则固定计算口径，不自动决定旅行、海拔、疾病、训练和生活因素的因果关系。
